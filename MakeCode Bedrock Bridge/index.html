使い方

Minecraft for Windows、Microsoft Edge、インターネット接続が必要です。

  1. Bridge を起動

    EXE を開きます。Node.js 版は ZIP を展開して Start.cmd を開きます。Edge に MakeCode が開いたら、Bridge の黒いウィンドウも開いたままにします。

  2. Minecraft から接続

    「設定 → 一般 → WebSocket を有効にする」をオンにします。チートが有効なワールドに入り、チャットでこのコマンドを送ります。

    /connect 127.0.0.1:19135

  3. MakeCode で実行

    黒いウィンドウに「接続済み」と表示されたら、MakeCode でプロジェクトを開き、▶ を押します。

チャットで動作を確認

新しいプロジェクトを作り、JavaScript に切り替えて貼り付けます。

JavaScript 
player.onChat("hello", function () {
    player.say("MakeCode OK!")
})

▶ を押して、Minecraft のチャットに hello と入力します。MakeCode OK! と出れば成功です。

よくある質問

Code Connection アプリは必要ですか？

不要です。旧 Code Connection や CodeConnectFix が起動中なら閉じてから、Bridge を起動してください。

接続できないときは？

WebSocket とワールドのチートがオンか、チャットの接続先が Bridge の黒いウィンドウに表示されたポートと同じかを確認してください。ワールドに入り直したら、接続コマンドをもう一度送ります。

暗号化の設定はどうしますか？

Minecraft の「暗号化された WebSocket の要求」はオンのまま、どちらの版でも接続できます。
